# To-Do List App 📝

## 📌 Project Overview

The To-Do List App is a simple task management application that helps users organize their daily activities. Users can add tasks, mark them as completed, and remove tasks when they are no longer needed.

This project was developed to improve my front-end development skills using HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and user-friendly interface
- Interactive task management
- Responsive design

## 🛠️ Technologies Used

- **HTML5** – Creates the application structure.
- **CSS3** – Adds styling and layout.
- **JavaScript** – Handles task management and user interactions.

## 📚 Key Concepts Practiced

- DOM Manipulation
- JavaScript Event Listeners
- Arrays and Functions
- Event Handling
- Responsive Web Design

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
